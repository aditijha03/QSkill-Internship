# 🌐 Text Translator App (React + Tailwind)

A simple React app that translates text between languages using **React Hooks** and a translation API.

## 🚀 Steps
1. **Setup**
   - Created project with `create-react-app`.
   - Added Tailwind CSS for styling.
   - Configured `.gitignore` to exclude `.env` and `node_modules`.

2. **Implementation**
   - Used `useState` for text, language, and translated output.
   - Added async `translateText` function with API call.
   - Error handling + loading state for better UX.

3. **Styling**
   - Tailwind classes directly in components.
   - Clean, responsive layout with centered container.
   - Styled button, textarea, and output card.

## ✅ Features
- Translate text into multiple languages.
- Shows loading state and error messages.
- Responsive UI with Tailwind.
